How the two halves talk

Every dashboard item carries its brain node. Open a task and the graph focuses on the file behind it, so a decision always has its source attached.

For one person

The repeating part of the day — triage, follow-ups, reminders, filing — runs itself. What is left is the work only you can do.

For a team

The same structure scales to a department: shared signals, one set of priorities, and a record of why each call was made.

Built, not proposed

Eleven dashboard versions, a generated graph rebuilt from the notes themselves, and a governance rulebook that keeps the demo offline.
