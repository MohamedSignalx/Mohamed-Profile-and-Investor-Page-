Design reference

LEAP Bright Style Kit

The palette, type and components behind the Mohamed Abuzaid profile and the SignalX pages. Everything here comes from one file — leap.css — which you can drop into any page, repo or deployment.

Colour

Violet leads, teal answers

Type

Space Grotesk sets, Jakarta reads

Display — Space Grotesk 700Headlines, buttons, labels. Tight tracking: −.025em to −.035em.
Body — Plus Jakarta Sans 400/600Paragraphs and UI text at 16px / 1.7.
Arabic — IBM Plex Sans ArabicApply .ar for RTL blocks; isolation handled.

Two headline treatments: gradient fill with .grad, or outline with .stroke on the second half of a split headline.

Reuse

Two lines to bring LEAP anywhere

Copy leap.css into any project, link it before your own stylesheet, and every token above is available.

<link href="https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700;800&family=Space+Grotesk:wght@500;600;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="leap.css">

In the profile repo it already ships at the root, next to theme.css. In a new repo, drop the file in and start with <div class="wrap">.
